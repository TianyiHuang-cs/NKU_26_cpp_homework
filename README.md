四、内容简介：
作品名字为《SOS！闭馆后》。这是一个结尾有反转的解密游戏。
场景设定是主角在图书馆赶ddl的时候睡着了，一觉醒来图书馆闭馆。
主角需要在图书馆的四层楼里探索解密，找到让时间倒流30分钟的方法，从而成功走出图书馆。
但是发现时间倒流后，仍然无法走出图书馆，是有别的方法吗……
这不仅是一次有趣的解密，更是以心理为主题的和解之旅。希望解密游戏能为你带来破解谜题的快乐，而这谜题也回答了关于如何面对ddl焦虑的问题。
